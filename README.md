# Personal Fantasy Football Analytics

A personal NFL fantasy football analytics and prediction system developed by Kevin Zieba.

## Project Overview

This project is a local Windows-based application designed to support fantasy football decision-making through statistical analysis, historical NFL data, and predictive modeling.

The application is intended for personal, noncommercial use in one Yahoo Fantasy Football league.

## Current Features

- Custom fantasy football scoring engine
- Historical NFL statistical database
- Position-specific player projection models
- Historical backtesting and model evaluation
- Excel dashboard with weekly rankings
- Player comparison tools
- Data validation and quality checks

## Planned Features

- Read-only Yahoo Fantasy Sports API integration
- Automatic league roster and matchup updates
- Injury and player availability analysis
- Trade evaluation and waiver-wire optimization
- Weekly matchup simulations
- Playoff probability modeling

## Yahoo Fantasy API Integration

The application requests read-only access to Yahoo Fantasy Football data for one league.

Requested information includes:
- League settings and scoring rules
- Fantasy team rosters
- League standings
- Weekly matchups and schedules
- Player ownership
- Historical fantasy scores

The application will not make roster changes, execute trades, or perform transactions.

Yahoo API authorization is currently pending.

## Privacy and Access

This project is intended for one user's personal use.

The application's source code, private league data, authentication credentials, and historical datasets are not published in this repository.

This repository currently serves as a public description of the project.
